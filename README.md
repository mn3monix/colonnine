# MeteoRoute

App su GitHub Pages: [https://mn3monix.github.io/colonnine/](https://mn3monix.github.io/colonnine/)

Confronta i percorsi Google Maps anche in base al meteo: temporali, grandine, vento forte e pioggia intensa.

Tutto gira nel browser. Le richieste vanno solo a Google Maps e a Open-Meteo.

## Avvio

1. Apri il sito.
2. In Impostazioni incolla la tua chiave Google Maps.
3. In Cloud Console autorizza il referrer `https://mn3monix.github.io/*` (e `http://localhost:8765/*` se testi in locale).
4. Abilita: Maps JavaScript API, Places API, Directions API.

La chiave resta solo nel `localStorage` del browser.

Sul telefono: Safari/Chrome → Aggiungi a Home.
